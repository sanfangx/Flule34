# Flule34

[简体中文](README.md) | [English](README_EN.md) | [日本語](README_JA.md) | **한국어**

Flule34는 Android용 비공식 Rule34Video Flutter 클라이언트입니다. 웹사이트의 기존 페이지, 엔드포인트와 동영상 소스를 사용하면서 모바일 탐색, 필터링, 재생, 다운로드와 로컬 정리 경험을 개선합니다.

이 프로젝트는 Rule34Video 공식 서비스와 관련이 없습니다. 거주 지역의 법정 성인 연령에 도달했으며 해당 콘텐츠에 합법적으로 접근할 수 있는 사용자만 이용해야 합니다.

## 주요 기능

### 탐색과 필터

- 최신, 인기, 높은 평점 및 구독 피드.
- 1열 및 2열 Masonry 레이아웃.
- 동영상, 태그, 카테고리, 아티스트 및 업로더 검색.
- 태그, 아티스트, 카테고리, 콘텐츠 성향, 길이, 업로드 시점, 좋아요 비율, 투표 수 및 제외 조건을 조합한 필터.
- 동영상 카드에 업로드 시점, 조회 수, 좋아요 비율, 투표 수와 길이를 표시합니다.

### 재생

- 1080p를 우선 사용하고, 없으면 더 낮은 최적 화질로 자동 전환합니다. 제공되는 경우 2160p도 지원합니다.
- 동영상 캐시, 재생 위치, 속도 및 화질 설정을 유지합니다.
- 전체 화면 조작, 화면 방향, 백그라운드 재생, 화면 켜짐 유지 및 반복 재생을 지원합니다.
- 화면을 500ms 동안 길게 누르면 일시적으로 2배속으로 재생되며 은은한 표시가 나타납니다.
- 재버퍼링 중에는 화면 중앙의 로딩 표시로 일시 정지 상태와 구분합니다.

### 라이브러리

- 웹사이트 즐겨찾기, 시청 기록 및 아티스트·업로더 구독.
- 계정과 무관한 로컬 라이브러리 및 사용자 정의 분류.
- 업데이트 시 사용자 데이터를 덮어쓰지 않는 내장 크리에이터 추천 라이브러리.
- 즐겨찾기, 기록 및 로컬 라이브러리 검색과 필터.
- 재생목록 생성, 이름 변경, 동영상 관리, 연속 재생, 반복 모드와 다음 항목 미리 불러오기.

### 다운로드와 계정

- 공용 폴더 `Download/Flule34`에 저장합니다.
- 백그라운드 작업, 알림, 일시 중지·재개, 재시도 및 작업 복구를 지원합니다.
- 외부에서 삭제되거나 이름 또는 내용이 변경된 파일을 검증합니다.
- 로그인 쿠키와 선택적으로 저장한 인증 정보를 Android 보안 저장소에 보관합니다.
- 공개 동영상 재생을 막지 않는 세션 복구.

### 언어와 콘텐츠 번역

- UI는 시스템 설정을 따르거나 중국어 간체, 영어, 일본어, 한국어 중에서 선택할 수 있습니다.
- 콘텐츠 번역은 UI 언어를 따르거나 네 언어 중 하나를 번역 대상으로 별도 지정할 수 있습니다.
- 중국어 간체 태그·카테고리 사전을 내장합니다. 다른 대상 언어에는 번역 서비스 또는 수동 번역을 사용합니다.
- 번역 라이브러리에서 내장, API 및 사용자 번역을 통합 관리하며 대상 언어·유형·출처 필터, 검색, 정렬, 편집과 일괄 작업을 지원합니다.
- 버전이 지정된 JSON 가져오기·내보내기로 대상 언어 정보를 보존합니다. 가져오기는 API 및 사용자 레이어만 병합하며 내장 사전을 교체하지 않습니다.
- Chat Completions, Responses, Anthropic Messages, DeepL 및 MyMemory 서비스를 여러 개 등록하고 순서를 지정해 자동 대체할 수 있습니다.
- AI 추론 매개변수는 서비스별 첫 요청에서 한 번만 확인하고 성공한 방식을 저장합니다.
- 제목, 카테고리 및 태그별로 자동 번역을 선택할 수 있습니다. 기본값은 모두 꺼짐이며 결과는 지속적으로 보관되는 로컬 데이터로 저장됩니다.
- 혼합 언어 원문을 기기의 추측만으로 건너뛰지 않습니다. AI와 DeepL은 자동 감지하고, MyMemory만 API 요구 사항 때문에 보수적인 문자 체계 추론을 사용합니다.
- 웹사이트 검색 결과와 저장된 제목·태그 번역에서 원문을 역검색한 결과를 함께 표시합니다.

## 설치

[GitHub Releases](https://github.com/Hanestl/Flule34/releases/latest)에서 최신 `arm64-v8a` APK를 다운로드하세요.

Android 7.0(API 24) 이상 ARM64 스마트폰과 태블릿을 지원합니다. 필요하면 브라우저 또는 파일 관리자의 '알 수 없는 앱 설치' 권한을 허용하세요. Release의 `SHA256SUMS.txt`로 APK 무결성을 확인할 수 있습니다.

## 데이터와 개인정보

- 로컬 라이브러리와 다운로드 기록은 기기에 저장되며 웹사이트 계정과 독립적입니다.
- 즐겨찾기, 기록, 구독 및 재생목록은 로그인한 웹사이트 계정에 연결됩니다.
- 다운로드 파일은 앱을 삭제해도 공용 폴더에 남습니다.
- 광고, 분석 또는 서드파티 비정상 종료 보고 SDK를 포함하지 않습니다.
- 민감 정보를 제거한 진단 로그는 기기에 7일 동안만 보관되며 '개인정보 및 데이터'에서 내보내거나 삭제할 수 있습니다. 자동으로 업로드하지 않습니다.
- 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 참조하세요.

## 빌드

검증된 환경: Flutter 3.44.8, Dart 3.12.2, JDK 17, Android SDK 36.

```powershell
flutter pub get
dart run build_runner build
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --split-per-abi --target-platform android-arm64 --no-pub
```

APK는 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`에 생성됩니다. 데이터베이스를 변경하면 Drift schema snapshot과 migration test도 업데이트해야 합니다.
