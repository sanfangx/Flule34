# Flule34

[简体中文](README.md) | [English](README_EN.md) | **日本語** | [한국어](README_KO.md)

Flule34 は Android 向けの非公式 Rule34Video Flutter クライアントです。サイトの既存ページ、エンドポイント、動画ソースを利用しながら、モバイルでの閲覧、絞り込み、再生、ダウンロード、ローカル整理を使いやすくします。

本プロジェクトは Rule34Video 公式とは関係ありません。居住地域の法定成年年齢に達し、当該コンテンツへのアクセスが法的に認められている方のみご利用ください。

## 主な機能

### 閲覧と絞り込み

- 新着、人気、高評価、フォロー中のフィード。
- 1列表示と2列のMasonry表示。
- 動画、タグ、カテゴリ、アーティスト、投稿者の検索。
- タグ、アーティスト、カテゴリ、コンテンツの傾向、長さ、投稿日、高評価率、投票数、除外条件などを組み合わせた絞り込み。
- 動画カードに投稿日、再生数、高評価率、投票数、長さを表示。

### 再生

- 1080pを優先し、利用できない場合は下位の最適画質へ自動で切り替えます。提供されている場合は2160pにも対応します。
- 動画キャッシュ、再生位置、再生速度、画質設定を保持します。
- 全画面操作、画面方向、バックグラウンド再生、画面点灯維持、ループ再生に対応します。
- 500ms長押しすると、一時的に2倍速で再生し、控えめなインジケーターを表示します。
- 再バッファ中は画面中央のローディング表示で一時停止と区別。

### ライブラリ

- サイトのお気に入り、視聴履歴、アーティスト・投稿者のフォロー。
- アカウントに依存しないローカルライブラリとカスタム分類。
- アップデート時もユーザーデータを上書きしない、組み込みのクリエイター別おすすめライブラリ。
- お気に入り、履歴、ローカルライブラリの検索と絞り込み。
- プレイリストの作成、名前変更、動画管理、連続再生、各種ループ、次の動画の先読み。

### ダウンロードとアカウント

- 共有フォルダー `Download/Flule34` へ保存します。
- バックグラウンド処理、通知、一時停止・再開、再試行、タスク復元に対応します。
- 外部で削除、改名、変更されたファイルを検証します。
- ログインCookieと任意の認証情報をAndroidのセキュアストレージに保存します。
- 公開動画の再生を妨げないセッション復元。

### 言語とコンテンツ翻訳

- UIはシステム設定に合わせるか、簡体字中国語、英語、日本語、韓国語から選択できます。
- コンテンツ翻訳はUI言語に合わせるか、4言語のいずれかを翻訳先として個別に指定できます。
- 簡体字中国語のタグ・カテゴリ辞書を内蔵しています。他の翻訳先言語では、翻訳サービスまたは手動翻訳を利用します。
- 翻訳ライブラリでは、組み込み訳、API訳、ユーザー訳を一元管理できます。翻訳先言語・種類・提供元での絞り込み、検索、並べ替え、編集、一括操作に対応しています。
- バージョン付きJSONのインポート・エクスポートで翻訳先言語を保持します。インポートではAPI・ユーザー層だけを統合し、組み込み辞書は置き換えません。
- Chat Completions、Responses、Anthropic Messages、DeepL、MyMemoryのサービスを複数登録し、並べ替えてフォールバックできます。
- AIの思考パラメーターはサービスごとに初回だけ検証し、成功した方式を保存します。
- タイトル、カテゴリ、タグごとに自動翻訳を選択できます。デフォルトではすべて無効で、結果は継続的に保持されるローカルデータとして保存されます。
- 混在言語の原文を端末側の推測だけでスキップしません。AIとDeepLは自動判定し、MyMemoryだけはAPI要件により保守的な文字種判定を使用します。
- サイト検索と、保存済みのタイトル・タグ訳から原文を逆引きした結果をまとめて表示します。

## インストール

[GitHub Releases](https://github.com/Hanestl/Flule34/releases/latest) から最新の `arm64-v8a` APK をダウンロードしてください。

Android 7.0（API 24）以降の ARM64 スマートフォン・タブレットに対応しています。必要に応じてブラウザまたはファイル管理アプリの「不明なアプリのインストール」を許可してください。Release の `SHA256SUMS.txt` で APK を検証できます。

## データとプライバシー

- ローカルライブラリとダウンロード記録は端末内に保存され、サイトアカウントとは独立しています。
- お気に入り、履歴、フォロー、プレイリストはログイン中のサイトアカウントに関連付けられます。
- ダウンロード済みファイルは、アプリをアンインストールしても共有フォルダーに残ります。
- 広告、分析、サードパーティ製のクラッシュレポートSDKは含まれていません。
- マスキング済み診断ログは端末内に7日間だけ保持され、「プライバシーとデータ」から出力・削除できます。自動送信は行いません。
- 詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## ビルド

確認済み環境：Flutter 3.44.8、Dart 3.12.2、JDK 17、Android SDK 36。

```powershell
flutter pub get
dart run build_runner build
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --split-per-abi --target-platform android-arm64 --no-pub
```

APK は `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` に生成されます。データベースを変更した場合は Drift schema snapshot と migration test も更新してください。

## 既知の制約

- 一覧、詳細、アカウント機能はサイトのHTML構造に依存します。
- 有効期限付きの動画URLは再取得が必要になる場合があります。
- 権限、課金、地域制限を回避する機能はありません。
