# HaRu 2.0.0

这是从 Flule34 1.6.0 到 HaRu 的大型版本更新。Hanime 不再是附加功能，而是与 R34V 地位相同、拥有独立浏览和账号体验的完整内容来源。

## 品牌与导航

- 项目正式更名为 **HaRu**，启用全新 H/R 共轴图标，并同步更新应用名称、文档、日志导出名称和更新地址；
- R34V、Hanime、媒体库和“我的”成为四个可自由排序的底部入口，启动时默认进入排在第一位的入口；
- 媒体库中的本机、R34V、Hanime 范围也可独立排序，两站相同功能保持一致的排列位置。

## Hanime 完整接入

- 新增 Hanime 首页，覆盖订阅、最新上市、最新上传及“他们在看”等站点栏目，并以最新上市作为默认栏目；
- 新增 Hanime 搜索和站点原生筛选，支持排序、发布日期、时长、类型、标签及品牌等组合条件；
- 支持登录状态、Cloudflare 验证与恢复，并为验证过程增加明确的等待、重试和诊断日志；
- 支持点赞与踩、稍后观看、观看历史、作者或上传者订阅、播放列表及对应的状态同步；
- 支持评论头像、赞踩、回复、回复展开和站点原生举报理由；
- 正确区分标题、简介、观看次数、发布时间、艺术家和上传者，并过滤网站用于添加或移除标签的控制项；
- 为 Hanime 列表增加缓存和相邻栏目预取，快速切回栏目时优先复用已有内容。

## 统一媒体库

- 媒体库重构为 **本机 / R34V / Hanime** 三个并列的一级范围，不再默认以任一站点为中心；
- 本机范围改为“本地库 / 下载”左右切换，本地分类库继续与网站账号完全独立；
- R34V 统一组织收藏、历史、播放列表和订阅，Hanime 对应组织点赞、稍后观看、历史、播放列表和订阅；
- 两站订阅页统一为订阅对象列表，进入对象详情后可浏览作品并在原页订阅或取消订阅；
- 针对不同站点校正筛选、排序和操作菜单，避免显示站点不支持或语义不一致的选项。

## 视频详情、播放与评论

- 重构视频详情页：压缩简介/评论切换栏，简介超过三行默认折叠，评论输入框在需要时展开；
- 暂停播放时可随简介或评论手势折叠播放器；播放、缓冲期间播放器保持固定，恢复播放时自动展开且保留正文滚动位置；
- Hanime 评论支持紧凑布局、回复输入、回复列表、赞踩和直接举报；R34V 评论补充评论者头像；
- 统一封面菜单与详情页的下载清晰度顺序，始终优先显示高画质；
- 修复 Hanime 标题引号解析、观看次数与点赞率混淆、简介元数据混排，以及稍后观看状态延迟等问题；
- 统一艺术家、上传者、订阅、搜索入口和站点名称，减少 R34V 与 Hanime 之间无设计依据的交互差异。

## 性能、可靠性与诊断

- 扩展首页缓存时长并保留栏目画面、滚动位置和筛选状态，降低重复切换造成的等待；
- 将预测预加载扩展到 Hanime，在后台准备相邻栏目和用户更可能打开的内容；
- 加强网络失败、页面结构变化、Cloudflare 验证和媒体源过期时的恢复与日志记录；
- 继续提供自动脱敏、容量受限、仅保留最近 7 天的本地诊断日志，日志绝不会自动上传；
- 补充 Hanime 页面快照、解析器、认证、筛选、媒体库、播放器和状态同步等自动化测试。

## 升级说明

- 仍然只发布 Android `arm64-v8a` APK，最低支持 Android 7.0（API 24）；
- 为保证旧版能够直接覆盖升级，Android 包名、签名证书和既有本地数据标识保持不变；
- 本项目与 Rule34Video、Hanime 官方均无关联，也不会绕过网站权限、地区限制或 Cloudflare 验证。
