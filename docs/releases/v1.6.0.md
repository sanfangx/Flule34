# Flule34 1.6.0

这是继 1.5.0 中文翻译体系之后的一次多语言与体验完善更新。

## 多语言界面

- 新增简体中文、English、日本語、한국어四套完整界面语言，可跟随系统或手动选择；语言选项始终显示各自原名；
- 默认 README 继续使用中文，并新增英文、日文、韩文 README，四份文档可在顶部互相切换；
- 补齐筛选、媒体库、翻译库、更新检查、下载、隐私、账号和动态状态等此前遗漏的界面本地化。

## 多语言内容翻译

- 内容翻译目标语言可跟随界面，也可独立选择简体中文、英语、日语或韩语；
- 用户译文和 API 已学习译文按目标语言独立保存，切换语言不会互相覆盖；内置标签与分类词表仍只用于简体中文；
- AI、DeepL 和 MyMemory 请求会使用当前目标语言；翻译归档也会保留站点、源语言和目标语言信息，并兼容 1.5.0 中文归档；
- 目标语言为英语时，本地语言识别会跳过高置信度纯英文原文，避免 AI 返回解释性文字；混合文本和不确定内容仍交给翻译服务；
- 目标语言为中文、日语或韩语时始终调用翻译服务；`3D → 3D` 等相同结果也会保存，双语模式明确显示为 `3D | 3D`。

## 显示与交互

- “外观设置”更名为“显示设置”；设置项统一使用说明在上、控件在下的纵向布局，并增加轻微底色区分相邻控件；
- 修复长文案在窄屏和英日韩界面下挤压、溢出的问题；
- 关闭视频菜单、筛选面板等非输入弹层后不再自动恢复搜索框焦点或弹出键盘；
- 本地诊断日志入口只显示占用大小，不再显示内部轮转文件数量。

## 数据与兼容性

- 数据库升级到 v13，1.5.0 的用户译文、API 译文和内置保护状态会无损迁移到简体中文分区；
- 用户手动译文继续保持最高优先级，API 已学习译文和本地设置不会被新版默认值或内置词表覆盖；
- 本版本仅提供 Android ARM64 APK，内部版本号为 `2031`，可直接覆盖安装 1.5.0 及此前的 1.6.0 测试包。
